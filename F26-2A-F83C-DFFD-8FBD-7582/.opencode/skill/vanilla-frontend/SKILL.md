# Regras de Interface Vanilla
- Utilize apenas HTML5, CSS3 e JavaScript puro (`fetch`, manipulação direta do DOM com `createElement`).
- Zero frameworks de CSS ou JS.
- Construa uma linha do tempo vertical estilizada em CSS puro com indicadores visuais para o nível de impedimento técnico.
- Mantenha obrigatoriamente a chave `F26-2A-F83C-DFFD-8FBD-7582` visível dentro da tag `<footer>` do `index.html`.
